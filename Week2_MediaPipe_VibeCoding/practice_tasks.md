# Week 2 실습 과제

## A. MediaPipe 관찰 과제

MediaPipe Pose Landmarker 웹 데모를 이용해 아래 동작 중 하나를 직접 수행합니다.

- 팔을 굽혔다 펴기
- 앉았다 일어서기
- 제자리에서 좌우로 이동하기

### 관찰 기록

아래 질문에 1~2문장으로 답하세요.

1. 어떤 신체 랜드마크가 가장 크게 움직였나요?
2. 동작 중 랜드마크가 흔들리거나 사라진 순간이 있었나요?
3. 조명, 카메라 거리, 가림이 인식 결과에 어떤 영향을 주었나요?

## B. Antigravity 필수 실습

### 1. 처음 입력한 프롬프트

`prompts.md`의 **1. 계획만 요청하기** 프롬프트를 입력하고 결과를 확인합니다.

### 2. 첫 번째 결과 화면

AI가 만든 프로그램을 실행한 뒤 첫 번째 결과 화면을 캡처합니다.

### 3. 수정 프롬프트 1개 이상

아래 중 하나 이상을 수행합니다.

- 왼쪽 무릎 각도 추가
- 화면 구성 수정
- 오른쪽 무릎 각도 추가
- 오류 메시지 전달 및 수정

### 4. 수정 전·후 비교

수정 전과 수정 후 무엇이 달라졌는지 **2~3문장**으로 작성합니다.

### 5. 검증

`prompts.md`의 **8. 코드와 결과의 한계 확인하기** 프롬프트를 사용해 AI가 만든 결과의 한계를 확인합니다.
