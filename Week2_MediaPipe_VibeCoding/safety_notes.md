# Week 2 AI·영상 활용 주의사항

## 1. MediaPipe 결과는 추정값입니다

MediaPipe Pose Landmarker는 영상에서 **신체 랜드마크의 위치를 추정**합니다. 결과는 다음 조건에 영향을 받을 수 있습니다.

- 카메라 위치와 촬영 방향
- 조명
- 몸의 일부가 가려지는 상황
- 화면 안에서 사람의 크기와 거리
- 배경의 복잡성

따라서 랜드마크가 표시되었다고 해서 항상 정확한 동작 분석 결과라고 볼 수는 없습니다.

## 2. 관절각도는 별도 계산값입니다

MediaPipe가 관절각도나 반복 횟수를 직접 판정하는 것은 아닙니다.

예를 들어 무릎 각도는 엉덩이-무릎-발목 랜드마크 좌표를 이용해 별도의 계산 로직으로 산출합니다. 이 계산값도 카메라 위치, 가림, 촬영 방향 등에 따라 오차가 생길 수 있습니다.

## 3. 의료적·안전 판정으로 단정하지 않습니다

이번 실습에서 만든 프로그램의 결과를 다음과 같이 표현하지 마세요.

- "이 자세는 부상 위험이다"
- "이 각도는 정상이다"
- "이 학생은 잘못된 자세를 하고 있다"

수업용 프로토타입의 목적은 **동작을 관찰하고 AI 코딩 과정을 체험하는 것**입니다. 실제 평가나 안전 판단은 교사가 결과의 한계를 확인한 뒤 결정해야 합니다.

## 4. 실제 학생 개인정보를 입력하지 않습니다

외부 AI 서비스에 다음 정보를 입력하거나 업로드하지 않습니다.

- 학생 이름·학번·연락처
- 학생 얼굴이 포함된 영상이나 사진
- 개인을 식별할 수 있는 건강·상담 정보
- 학교에서 비공개로 관리하는 자료

실습은 본인 또는 가상의 상황을 사용하고, 실제 학생 영상이 필요한 경우에는 학교의 관련 규정과 승인 절차를 먼저 확인합니다.

## 5. AI가 만든 코드는 반드시 직접 실행합니다

AI 코딩 도구가 코드를 생성했다고 해서 정상적으로 작동하는 것은 아닙니다.

**요청 → 계획 확인 → 생성 → 실행 → 오류 확인 → 수정 → 재실행**

이 과정을 반복하고, 오류 메시지가 나오면 내용을 그대로 전달해 수정 원인을 확인합니다.

## 6. 교사가 최종 확인합니다

AI가 만든 결과를 실제 체육 수업에 사용하기 전에는 다음을 확인합니다.

- 프로그램이 의도한 기능만 수행하는가?
- 랜드마크와 계산값이 화면상 동작과 대체로 일치하는가?
- 오류가 발생했을 때 학생에게 잘못된 정보를 주지 않는가?
- 개인정보나 영상정보를 저장·전송하지 않는가?
- 실제 수업에서 안전하게 사용할 수 있는가?

AI 도구는 수업 준비와 프로토타입 제작을 돕는 보조도구로 사용합니다.
