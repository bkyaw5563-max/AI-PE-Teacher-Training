# Week 2. AI 도구 활용 및 바이브 코딩

이번 주에는 **MediaPipe Pose Landmarker**로 신체 랜드마크를 직접 확인하고, **Google Antigravity**와 같은 에이전트형 개발 도구에 자연어로 요청하여 간단한 체육수업용 동작 분석 도구의 프로토타입을 만들어 봅니다.

## 학습목표

이번 주 학습 후 학생은 다음을 할 수 있어야 합니다.

- MediaPipe가 무엇이고, 웹 브라우저에서 사람의 동작을 어떻게 인식하는지 설명할 수 있다.
- MediaPipe 데모를 이용해 신체 랜드마크(키포인트)를 직접 확인할 수 있다.
- 바이브 코딩(vibe coding)의 개념을 예시와 함께 설명할 수 있다.
- Google Antigravity 같은 에이전트형 개발 도구에 자연어로 요청하고, 생성된 결과를 실행·검토·수정하는 과정을 이해할 수 있다.

## 준비물

- 인터넷 연결 노트북(웹캠 내장 또는 연결)
- Chrome 또는 Edge 등 웹 브라우저
- 개인 Google 계정
- Google Antigravity 2.0 사전 설치 및 로그인 확인

## 권장 학습순서

1. 제2장 교재의 MediaPipe 개념 부분을 읽습니다.
2. MediaPipe Pose Landmarker 웹 데모에서 예시 이미지와 웹캠을 이용해 신체 랜드마크를 확인합니다.
3. 팔 굽히기, 앉았다 일어서기, 좌우 이동 중 한 동작을 수행하고 랜드마크 변화를 관찰합니다.
4. `prompts.md`의 **필수 실습 1~2**를 순서대로 Antigravity에 입력합니다.
5. 생성된 결과를 직접 실행한 뒤 **후속 프롬프트 3~5**로 기능과 화면을 수정합니다.
6. 오류가 있으면 `prompts.md`의 오류 해결 프롬프트를 사용합니다.
7. 마지막으로 AI가 만든 결과의 한계와 개인정보·안전 주의사항을 점검합니다.
8. `practice_tasks.md`의 제출 항목을 정리합니다.

## 핵심 개념

### MediaPipe Pose Landmarker

Pose Landmarker는 사람의 몸에서 어깨·팔꿈치·손목·골반·무릎·발목 등을 포함한 **33개의 신체 랜드마크**를 추정하고 좌표와 가시성 정보를 제공합니다.

MediaPipe가 관절각도나 반복 횟수를 직접 판정하는 것은 아닙니다. 필요한 경우 랜드마크 좌표를 이용해 별도의 계산 로직을 작성합니다.

### 바이브 코딩

바이브 코딩은 AI에게 자연어로 원하는 기능을 설명하고, 생성된 코드를 실행한 뒤 결과를 보며 반복적으로 수정하는 개발 방식입니다.

이번 실습의 핵심 흐름은 다음과 같습니다.

**요청 → 계획 확인 → 생성 → 실행 → 결과 확인 → 수정 요청 → 재실행**
