# Week 2 학생 실습용 프롬프트

MediaPipe 웹 데모는 프롬프트 없이 직접 체험합니다. 이후 **Google Antigravity**에서 아래 프롬프트를 순서대로 복사해 사용합니다.

처음부터 완벽한 프로그램을 만들려고 하지 말고, 결과를 실행한 뒤 후속 명령으로 하나씩 수정하세요.

---

## A. 필수 실습 — 동작 인식 웹 도구 만들기

### 1. 처음에는 계획만 요청하기

```text
나는 프로그래밍 초보자인 예비체육교사야.
MediaPipe Pose Landmarker를 이용해서 웹캠 영상 위에 사람의 신체 랜드마크와 스켈레톤을 표시하는 간단한 웹 도구를 만들고 싶어.

조건:
- 브라우저에서 실행되는 간단한 웹페이지
- 웹캠 시작/중지 버튼 포함
- 사람의 주요 신체 랜드마크와 연결선을 화면에 표시
- 화면은 대학생이 보기 쉽게 단순하게 구성
- 실제 학생 개인정보를 저장하거나 외부 서버로 전송하지 않도록 구성
- 가능한 한 간단한 구조로 만들기

아직 파일을 만들거나 코드를 작성하지 말고,
먼저 어떤 파일과 기능이 필요한지 초보자가 이해할 수 있게 작업 계획만 설명해줘.
```

### 사용 포인트
AI가 바로 파일을 만들기 전에 무엇을 하려는지 확인하는 단계입니다.

---

### 2. 계획 확인 후 제작 요청하기

```text
방금 제안한 계획대로 만들어줘.
MediaPipe Pose Landmarker를 사용하고, 웹캠 영상 위에 신체 랜드마크와 스켈레톤이 실시간으로 보이게 해줘.

완성되면:
1) 어떤 파일을 만들었는지
2) 어떻게 실행하는지
3) 웹캠 권한을 어디서 허용하는지
4) 정상적으로 작동하면 화면에서 무엇이 보여야 하는지
초보자도 이해할 수 있게 설명해줘.
```

### 사용 포인트
AI가 만든 뒤에는 반드시 실제 실행 화면을 확인합니다.

---

## B. 결과를 보면서 수정하는 후속 프롬프트

### 3. 무릎 각도 하나 추가하기

```text
현재 프로그램은 그대로 유지하면서 기능 하나만 추가해줘.

왼쪽 무릎의 2차원 각도를
엉덩이-무릎-발목 세 점을 이용해 계산하고,
화면 오른쪽 위에 'Left Knee Angle: 000°' 형식으로 표시해줘.

중요:
- MediaPipe 자체가 각도를 직접 판정하는 것처럼 설명하지 말 것
- 랜드마크 좌표를 이용해 별도로 계산한다는 것을 주석이나 설명에 남길 것
- 의료적 판단이나 부상 위험 판정은 하지 말 것
- 수정 후 실행 방법과 변경된 부분을 짧게 설명해줘.
```

### 사용 포인트
랜드마크 좌표와 별도로 계산한 값을 구분하는 연습입니다.

---

### 4. 화면을 보기 쉽게 수정하기

```text
기능은 그대로 유지하고 화면만 더 보기 쉽게 수정해줘.

- 웹캠 화면을 중앙에 배치
- 무릎 각도 숫자를 더 크게 표시
- 시작/중지 버튼을 눈에 잘 띄게 배치
- 설명 문장은 최소화
- 모바일보다는 노트북 화면을 기준으로 구성

수정한 뒤 어떤 부분을 바꿨는지 5줄 이내로 알려줘.
```

### 사용 포인트
바이브 코딩에서는 기능뿐 아니라 화면 구성도 자연어로 반복 수정할 수 있습니다.

---

### 5. 오른쪽 무릎도 추가하기

```text
왼쪽 무릎 각도 기능은 유지하고,
같은 방식으로 오른쪽 무릎 각도도 추가해줘.

화면에는 Left Knee Angle과 Right Knee Angle을 동시에 표시하고,
좌우가 헷갈리지 않도록 라벨을 명확하게 써줘.
기존 기능이 망가지지 않았는지도 확인해줘.
```

### 사용 포인트
기존 기능을 유지한 채 작은 기능을 추가하는 연습입니다.

---

## C. 오류가 생겼을 때 사용하는 프롬프트

### 6. 오류 메시지를 그대로 전달하기

```text
프로그램을 실행했는데 아래 오류가 발생했어.

[여기에 오류 메시지를 그대로 붙여넣기]

추측해서 여러 부분을 한꺼번에 바꾸지 말고,
1) 오류가 발생한 가능성이 높은 원인
2) 수정해야 할 파일과 위치
3) 최소한의 수정 방법
을 먼저 설명한 뒤 수정해줘.

수정 후에는 내가 다시 확인해야 할 항목도 알려줘.
```

### 사용 포인트
오류 메시지를 삭제하거나 요약하지 말고 그대로 붙여넣는 것이 좋습니다.

---

### 7. 카메라가 켜지지 않을 때

```text
웹페이지는 열리는데 웹캠이 시작되지 않아.
현재 코드를 확인해서 가능한 원인을 점검해줘.

특히 아래 항목을 확인해줘.
- 브라우저 카메라 권한
- HTTPS 또는 localhost 실행 여부
- 웹캠 장치 선택 문제
- JavaScript 오류
- MediaPipe 모델/라이브러리 로딩 문제

코드를 무조건 바꾸기 전에 내가 먼저 확인할 수 있는 순서부터 알려줘.
```

### 사용 포인트
코드 문제가 아닌 브라우저 권한이나 실행환경 문제일 수도 있습니다.

---

## D. AI가 만든 결과 검증하기

### 8. 코드와 결과의 한계 확인하기

```text
현재 만든 프로그램을 체육수업에서 사용할 수 있는지 검토해줘.

다음 항목을 표로 정리해줘.
- 현재 프로그램이 실제로 하는 일
- MediaPipe가 직접 제공하는 값
- 코드에서 별도로 계산한 값
- 카메라 각도나 가림 때문에 오차가 커질 수 있는 상황
- 실제 수업 전에 교사가 확인해야 할 사항
- 개인정보 및 영상정보 보호 시 주의할 점

확실하지 않은 내용은 '확인 필요'라고 표시해줘.
```

### 사용 포인트
AI가 만든 기능을 곧바로 정확한 평가도구로 사용하지 않고 한계를 확인합니다.

---

## E. 나만의 체육 도구 만들기 — 빈칸형 프롬프트

### 9. 종목에 맞춰 바꾸어 사용하기

```text
나는 예비체육교사야.
[학년] 학생의 [종목/동작] 수업에서 사용할 간단한 웹 도구를 만들고 싶어.

관찰하고 싶은 것은 [관찰 항목]이고,
화면에는 [표시하고 싶은 정보]를 보여주고 싶어.

MediaPipe Pose Landmarker의 신체 랜드마크를 활용하되,
MediaPipe가 제공하지 않는 값은 좌표를 이용해 별도로 계산해줘.

조건:
- 프로그래밍 초보자가 이해할 수 있는 간단한 구조
- 결과를 의료적 진단이나 부상 위험 판정으로 표현하지 않기
- 실제 학생 개인정보를 저장하지 않기
- 먼저 작업 계획을 제시하고 내 확인을 받은 뒤 구현하기
- 완성 후 실행 방법과 한계를 설명하기
```

### 사용 예시
`중학교 2학년 / 배구 서브 / 팔꿈치 각도 / 좌우 팔꿈치 각도와 스켈레톤`

---

## 실습 원칙

- 실제 학생의 이름·학번·연락처·얼굴 영상 등 개인정보를 외부 AI 서비스에 입력하지 않습니다.
- MediaPipe의 랜드마크 추정값은 카메라 위치, 가림, 조명, 촬영 방향 등에 영향을 받을 수 있습니다.
- 랜드마크 좌표를 이용해 계산한 관절각도도 오차가 있을 수 있습니다.
- AI가 만든 코드와 분석 결과는 반드시 직접 실행하고 확인합니다.
- 수업 평가나 안전 판단에 사용할 때에는 교사가 결과와 한계를 최종 확인합니다.
