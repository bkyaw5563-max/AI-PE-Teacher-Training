# Week 3 교육용 동영상 안내

## 3주차 전체 Scrimba 교육영상

▶ **AI 기반 체육 수업지도안 설계 — 전체 영상**  
https://scrimba.com/explain/guide0c0em9fi8?claim=m4c3pj3irlekpto0&fullscreen=1

이번 영상은 3주차 내용을 짧은 영상 여러 개로 나누지 않고 **처음부터 끝까지 한 편으로** 구성했습니다.

## 영상에서 다루는 내용

1. 3주차 학습목표와 전체 흐름
2. 체육 지도안에서 AI와 교사의 역할 구분
3. 좋은 지도안 프롬프트의 네 요소
   - 역할·맥락
   - 구체적 조건
   - 목표·성취기준
   - 형식
4. 막연한 프롬프트와 구체적인 프롬프트 비교
5. ChatGPT·Claude·Gemini 활용 방식
6. 첫 지도안 초안에서 확인할 내용
7. 체육 지도안 검토의 다섯 기준
   - 안전
   - 발달단계 적합성
   - 성취기준 연계
   - 실제 활동시간 확보
   - 평가계획 연계
8. 할루시네이션과 사실 검증
9. 막연한 안전 문장을 구체적인 행동으로 수정하기
10. 활동 난이도 조절하기
11. 실제 신체활동 시간 점검하기
12. 성취기준 원문 검증하기
13. 4주차 평가용 관찰 행동으로 연결하기
14. 최종 지도안 초안 만들기
15. 실습 제출물과 확인문제
16. 4주차 AI 활용 학생 평가 예고

## 영상을 보면서 실습하는 방법

영상 전체를 먼저 한 번 시청한 뒤 `prompts.md`를 열어 순서대로 실습하는 것을 권장합니다.

### 권장 순서

**영상 시청 → 프롬프트 1로 초안 생성 → 프롬프트 2로 진단 → 3~7로 수정·검증 → 프롬프트 8로 최종 초안 → 과제 제출**

## 영상과 교재를 함께 사용할 때

- 영상은 전체 흐름을 이해하는 용도로 사용합니다.
- 구체적인 명령어는 `prompts.md`에서 복사해 사용합니다.
- 제출 항목은 `practice_tasks.md`에서 확인합니다.
- 성취기준·규칙·수치·안전 관련 내용은 공식 자료에서 다시 확인합니다.

> Scrimba 영상은 웹 기반 설명 영상입니다. 서비스 화면이나 AI 도구의 기능은 업데이트될 수 있으므로, 특정 버튼 위치보다 **수업 설계와 검토의 작업 흐름**을 중심으로 학습하세요.
