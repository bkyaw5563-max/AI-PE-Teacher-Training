# Week 3 학생 실습용 프롬프트

아래 프롬프트는 **ChatGPT·Claude·Gemini 중 하나를 선택해** 순서대로 사용합니다. 처음부터 완성본을 요구하지 말고, **초안 생성 → 진단 → 수정 → 검증 → 최종 초안** 순서로 진행하세요.

## 실습 전에 먼저 준비할 정보

- 학년
- 종목/단원
- 차시
- 수업시간
- 학생 수
- 수업 장소
- 사용 가능한 기구와 수량
- 학습목표
- 공식 교육과정에서 확인한 성취기준 원문

성취기준을 아직 확인하지 못했다면 빈칸으로 두고, AI에게 새 코드를 만들게 하지 않습니다.

---

## 필수 실습 1. 지도안 초안 만들기

```text
너는 중학교 체육 교사의 수업 설계를 돕는 보조자야.

다음 조건으로 1차시 체육 수업지도안 초안을 만들어줘.

[수업 조건]
- 학년: [학년]
- 종목/단원: [종목 또는 단원]
- 차시: [예: 3차시 중 1차시]
- 수업시간: [예: 45분]
- 학생 수: [예: 28명]
- 장소: [예: 실내 체육관]
- 사용 가능한 기구: [기구와 수량]
- 학생 수준 또는 고려사항: [가상의 조건만 작성]

[학습목표]
- [이번 차시 학습목표]

[공식 성취기준]
- [공식 교육과정에서 확인한 성취기준 원문을 붙여넣기]
- 성취기준을 제공하지 않았다면 코드나 문구를 새로 만들지 말고 '확인 필요'라고 표시해줘.

[출력 형식]
도입-전개-정리로 나누고 표로 작성해줘.
표에는 '단계 / 시간 / 교사 활동 / 학생 활동 / 준비물 / 안전 유의사항'을 포함해줘.
마지막에 총 시간이 내가 제시한 수업시간과 맞는지도 확인해줘.
```

### 확인할 것
- 역할·맥락이 들어갔는가?
- 학년·인원·시간·장소·기구가 반영되었는가?
- 성취기준을 AI가 임의로 만들지 않았는가?
- 시간 합계가 실제 수업시간과 맞는가?

## 필수 실습 2. 수정 전에 문제점부터 진단하기

```text
방금 만든 지도안은 아직 수정하지 말고, 먼저 문제점을 점검해줘.

아래 5가지 기준으로 각각
'괜찮은 점 / 수정이 필요한 점 / 수정 이유'를 표로 정리해줘.

1) 안전
2) 발달단계 적합성
3) 성취기준 연계
4) 실제 활동시간 확보
5) 평가계획 연계

확실하지 않은 내용은 추측하지 말고 '확인 필요'라고 표시해줘.
```

---

## 필수 실습 3. 안전 항목 구체화하기

```text
현재 지도안의 전체 구조는 유지하고 안전 항목만 수정해줘.

다음 사항을 구체적으로 점검해줘.
- 준비운동과 정리운동
- 학생 간 충돌 가능성
- 미끄러짐 또는 넘어짐
- 공이나 기구에 맞을 가능성
- 기구 배치와 이동 동선
- 교사가 수업 전에 확인해야 할 시설 상태

'조심한다', '안전에 유의한다' 같은 막연한 문장보다
교사가 실제로 확인하거나 지도할 수 있는 행동으로 바꿔줘.
의료적 진단이나 과도한 안전 보장은 하지 말아줘.
```

---

## 필수 실습 4. 활동 난이도 조절하기

```text
현재 지도안의 전개 활동을 학생 수준에 맞게 조정해줘.

같은 학습목표를 유지하면서 각 핵심 활동마다
- 기본 수준
- 쉬운 대안
- 도전 수준
을 제시해줘.

학생을 능력으로 고정해서 분류하지 말고,
학생이 상황에 따라 선택하거나 교사가 조절할 수 있는 방식으로 작성해줘.
수정된 부분만 보여줘.
```

---

## 필수 실습 5. 실제 활동시간 확인하기

```text
현재 지도안의 시간 배분을 다시 점검해줘.

1) 도입·전개·정리 시간을 모두 더해 총 수업시간과 맞는지 계산하고
2) 설명, 대형 정비, 이동 같은 관리 시간을 구분하고
3) 학생이 실제로 움직이는 활동시간이 어느 정도인지 추정해줘.

시간 합계가 맞지 않거나 관리 시간이 지나치게 길다면
전체 수업시간은 유지한 채 수정안을 제안해줘.
추정한 값은 '추정'이라고 표시해줘.
```

## 필수 실습 6. 사실 확인이 필요한 부분 찾기

```text
현재 지도안에서 사실 확인이 필요한 내용을 찾아줘.

특히 아래를 확인해줘.
- 성취기준 코드와 문구
- 스포츠 규칙
- 수치나 거리, 시간 기준
- 안전 관련 기준
- 학교 규정으로 오해할 수 있는 내용

내가 제공하지 않은 공식 성취기준 코드나 문구는 새로 만들지 말고,
검증이 필요한 항목은 '확인 필요'라고 표시해줘.

결과는 '항목 / 현재 문장 / 왜 확인이 필요한지 / 어디에서 확인할지' 표로 정리해줘.
```

### 반드시 직접 확인할 것
AI가 표시한 항목 중 최소 1개는 공식 교육과정, 공식 경기규칙, 학교 자료 등에서 직접 확인하세요.

## 필수 실습 7. 4주차 평가와 연결하기

```text
현재 지도안의 학습목표와 핵심 활동을 보고,
다음 주에 수행평가 루브릭을 만들 수 있도록 관찰 가능한 행동을 정리해줘.

조건:
- 아직 점수나 등급을 확정하지 말 것
- 관찰 가능한 행동만 제시할 것
- 학생의 성격이나 태도를 추측하지 말 것
- 기술 수행, 참여, 안전 행동처럼 수업에서 직접 볼 수 있는 내용 중심으로 작성

결과는 '학습목표 / 관찰 가능한 행동 / 관찰 시점' 표로 정리해줘.
```

## 필수 실습 8. 최종 지도안 초안 다시 작성하기

```text
지금까지 확인한 수정 사항을 반영해 지도안 초안을 다시 작성해줘.

반드시 반영할 것:
- 안전 점검 결과
- 수준별 난이도 조절
- 전체 시간 합계
- 실제 활동시간을 고려한 구성
- 내가 제공한 공식 성취기준만 사용
- 4주차 평가로 연결 가능한 관찰 행동

출력은 '단계 / 시간 / 교사 활동 / 학생 활동 / 준비물 / 안전 유의사항 / 평가 연결' 표로 작성해줘.

표 아래에는 별도로
1) 교사가 수업 전에 최종 확인할 내용
2) 공식 자료에서 다시 확인해야 할 내용
을 구분해서 적어줘.
```

## 선택 활동 9. 다른 AI와 결과 비교하기

1번에서 사용한 **동일한 프롬프트**를 다른 AI에 입력합니다.

비교 기준:
- 조건 반영 정도
- 활동의 구체성
- 시간 배분
- 안전성
- 성취기준 처리 방식
- 실제 수업 적용 가능성

AI 이름만 보고 판단하지 말고 실제 출력 내용을 기준으로 비교하세요.

---

## 실습 원칙

- 실제 학생의 이름·학번·연락처·상담 내용·건강정보 등을 입력하지 않습니다.
- AI가 제시한 성취기준, 규칙, 수치, 안전 관련 내용은 공식 자료와 대조합니다.
- AI가 만든 지도안은 수업 준비를 위한 초안입니다.
- 실제 수업의 목표·활동·평가·안전 판단은 교사가 최종 결정합니다.
