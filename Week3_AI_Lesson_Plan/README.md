# Week 3. AI 기반 체육 수업지도안 설계

3주차에는 생성형 AI를 이용해 체육 수업지도안 초안을 만들고, **체육 교사의 기준으로 검토·수정·검증**하는 과정을 실습합니다.

## 전체 교육영상

▶ **Scrimba 3주차 전체 교육영상**  
https://scrimba.com/explain/guide0c0em9fi8?claim=m4c3pj3irlekpto0&fullscreen=1

영상은 다음 흐름을 한 번에 다룹니다.

**프롬프트 구성 → 지도안 초안 생성 → 체육 교과 기준 검토 → 수정 → 공식 자료 검증 → 최종 초안 → 4주차 평가 연결**

## 학습목표

이번 주 학습 후 학생은 다음을 할 수 있어야 합니다.

- 좋은 지도안 프롬프트의 네 요소인 **역할·맥락 / 구체적 조건 / 목표·성취기준 / 형식**을 설명할 수 있다.
- ChatGPT·Claude·Gemini 중 하나 이상을 이용해 체육 수업지도안 초안을 만들 수 있다.
- AI가 만든 초안을 **안전·발달단계·성취기준·실제 활동시간·평가계획 연계**의 관점에서 검토할 수 있다.
- 생성형 AI의 할루시네이션 가능성을 이해하고 성취기준·규칙·수치 등을 공식 자료와 대조할 수 있다.

## 준비물

- 인터넷 연결 노트북
- ChatGPT·Claude·Gemini 중 최소 1개 계정
- 2주차에서 정한 학년·종목
- 수업시간, 학생 수, 장소, 사용 가능한 기구 등의 수업 조건
- 가능한 경우 공식 교육과정에서 확인한 성취기준 원문

## 권장 학습순서

1. 위의 **3주차 전체 Scrimba 영상**을 시청합니다.
2. `prompts.md`의 **필수 실습 1**로 지도안 초안을 생성합니다.
3. **필수 실습 2**로 초안의 문제점을 먼저 진단합니다.
4. 안전·난이도·활동시간·성취기준을 순서대로 수정하고 검증합니다.
5. 4주차 평가에 사용할 **관찰 가능한 행동**을 정리합니다.
6. 최종 지도안 초안을 다시 작성합니다.
7. `practice_tasks.md`의 제출 항목을 정리합니다.
8. `safety_notes.md`에서 개인정보·사실검증·교사 최종판단 원칙을 확인합니다.

## 체육 지도안 검토 5항목

1. **안전** — 준비운동·정리운동, 시설, 기구, 이동 동선, 충돌·미끄러짐 가능성을 확인합니다.
2. **발달단계 적합성** — 학생 수준에 맞는 쉬운 대안과 도전 수준을 마련합니다.
3. **성취기준 연계** — AI가 만든 코드나 문구를 그대로 사용하지 않고 공식 원문과 대조합니다.
4. **실제 활동시간 확보** — 설명·대기·대형 정비 시간이 너무 길지 않은지 확인합니다.
5. **평가계획 연계** — 학습목표가 다음 주 수행평가의 관찰 가능한 행동으로 이어지는지 확인합니다.

## 이번 주 핵심 원칙

> **AI가 만든 지도안은 초안입니다.**  
> 실제 수업의 목표·활동·평가·안전 판단은 교사가 최종 결정합니다.
