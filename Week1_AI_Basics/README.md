# Week 1. AI 체육 융합의 필요성과 기초지식

## 전체 교육영상

▶ **Scrimba 1주차 전체 영상**  
https://scrimba.com/explain/guide0g5mcq5m0?fullscreen=1

이 영상은 1주차 내용을 한 편으로 이어서 학습할 수 있도록 구성했습니다. 체육교육에서 AI가 필요한 이유부터 AI·머신러닝·딥러닝, 생성형 AI 활용, 좋은 프롬프트 만들기, 컴퓨터비전과 MediaPipe 예고까지 순서대로 설명합니다.

## 학습목표

이번 주 학습 후 학생은 다음을 할 수 있어야 합니다.

- 체육교육에서 AI 활용이 필요한 이유를 설명할 수 있다.
- 인공지능(AI), 머신러닝(ML), 딥러닝(DL)의 관계를 구분할 수 있다.
- ChatGPT·Claude·Gemini 중 하나를 선택해 체육 수업 관련 질문을 해볼 수 있다.
- 컴퓨터비전이 사람의 동작을 인식하는 기본 원리를 설명할 수 있다.

## 권장 학습순서

1. 위 **1주차 전체 교육영상**을 시청합니다.
2. 제1장 교재를 읽으며 영상의 핵심 내용을 다시 확인합니다.
3. 생성형 AI 도구 1개를 선택합니다.
4. `prompts.md`의 필수 프롬프트 1~3을 수행합니다.
5. 같은 대화에서 후속 명령으로 답변을 다듬습니다.
6. `practice_tasks.md`의 성찰 과제를 작성합니다.
7. `safety_notes.md`의 개인정보·안전 주의사항을 확인합니다.

## 영상에서 확인할 핵심 내용

- 체육교육에서 AI를 활용할 수 있는 이유와 교사의 역할
- AI·머신러닝·딥러닝의 관계
- 생성형 AI와 할루시네이션, 결과 검증의 필요성
- 체육 수업 아이디어를 요청하고 조건을 추가해 답변을 수정하는 방법
- 좋은 프롬프트의 핵심 요소: 역할, 맥락, 조건, 출력 형식
- 질문 → 답변 확인 → 조건 추가 → 수정 → 재확인의 반복 과정
- 컴퓨터비전과 신체 랜드마크(키포인트)의 기본 개념
- 2주차 MediaPipe 실습으로의 연결
