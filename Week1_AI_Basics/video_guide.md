# Week 1 교육용 동영상 안내

교육용 영상은 한 편의 긴 강의보다 짧은 영상으로 나누는 것을 권장합니다.

## 권장 영상 구성

1. **왜 체육 교사에게 AI가 필요한가?** — 약 6~7분
2. **AI·머신러닝·딥러닝·생성형 AI** — 약 7~8분
3. **생성형 AI로 체육 수업 아이디어 만들기** — 약 10~12분
4. **컴퓨터비전과 MediaPipe 예고** — 약 6~7분

## 우선 제작 권장 영상

### 생성형 AI로 체육 수업 아이디어 만들기

권장 순서:

1. ChatGPT·Claude·Gemini 중 한 가지 선택
2. `prompts.md`의 필수 실습 1 입력
3. 첫 답변에서 학년·인원·시간·안전 조건 확인
4. 필수 실습 2로 조건 추가
5. 필수 실습 3으로 안전 관점 재검토
6. 사실 확인이 필요한 내용 표시
7. 학생 과제 안내

## 촬영 시 주의사항

- 실제 학생 개인정보가 보이지 않도록 데모 상황을 사용합니다.
- 서비스 UI는 바뀔 수 있으므로 영상에 ‘2026.09 기준’ 표기를 권장합니다.
- 화면 녹화 시 글자가 잘 보이도록 브라우저 확대를 적절히 조정합니다.
- 가능하면 자막 또는 대본을 제공합니다.
