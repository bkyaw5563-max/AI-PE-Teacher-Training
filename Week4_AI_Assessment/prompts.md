# Week 4 학생 실습용 프롬프트

아래 프롬프트는 **3주차에서 만든 체육 수업지도안**을 준비한 뒤 ChatGPT·Claude·Gemini 중 한 가지 도구에서 순서대로 사용합니다.

> 실제 학생의 이름·학번·얼굴·음성·건강정보 등 식별 가능한 자료는 외부 AI 서비스에 입력하지 않습니다.

---

## 1. 관찰 체크리스트 초안 만들기

```text
너는 중학교 체육 교사의 수행평가 설계를 돕는 보조자야.

아래 수업 정보를 바탕으로 학생 수행을 관찰할 체크리스트 초안을 만들어줘.

[수업 정보]
- 학년: [학년]
- 종목/단원: [종목 또는 단원]
- 차시: [차시]
- 학습목표: [3주차 지도안의 학습목표]
- 핵심 활동: [수업의 핵심 활동]
- 공식 성취기준: [공식 원문을 확인한 뒤 붙여넣기]

[조건]
- 관찰 항목은 눈으로 확인 가능한 행동으로 작성
- 필요한 경우 준비-실행-마무리 단계로 나누기
- '잘한다', '안정적이다'처럼 모호한 표현은 피하기
- 필요한 경우 성공 횟수나 빈도를 기록할 칸 포함
- 결과뿐 아니라 수업에서 관찰 가능한 과정 요소도 포함
- 학생의 성격이나 태도를 추측하지 말 것

[출력 형식]
'평가 요소 / 관찰 가능한 행동 / 기록 방법 / 비고' 표로 정리해줘.
```

## 2. 모호한 문장만 찾아 고치기

```text
방금 만든 체크리스트에서 교사마다 다르게 해석할 수 있는 모호한 표현을 찾아줘.

각 문장을
1) 현재 표현
2) 왜 모호한지
3) 눈으로 확인 가능한 표현으로 수정한 문장
형식의 표로 정리해줘.

특히 '잘한다', '적극적이다', '안정적이다', '협력적이다'처럼
관찰자에 따라 판단이 달라질 수 있는 표현을 우선 확인해줘.
```

---

## 3. 상·중·하 루브릭 초안 만들기

```text
위 체크리스트와 학습목표를 바탕으로 수행평가 루브릭 초안을 만들어줘.

조건:
- 평가 수준은 상·중·하 3단계
- 각 단계의 기준 문장이 서로 겹치지 않게 작성
- 실제 수업 중 교사가 눈으로 확인할 수 있는 행동으로 작성
- 가능하면 횟수, 빈도, 수행 여부 등 관찰 가능한 근거를 사용
- 특정 체격이나 기존 운동 경험만으로 유리해지지 않도록 주의
- 내가 제공하지 않은 성취기준 코드나 문구는 새로 만들지 말 것

결과는
'평가 요소 / 상 / 중 / 하 / 관찰 방법'
표로 정리해줘.
```

---

## 4. 수준 구분이 겹치는지 검토하기

```text
방금 만든 루브릭에서 상·중·하 기준이 서로 겹치거나 경계가 애매한 항목을 찾아줘.

각 항목별로
- 현재 상 기준
- 현재 중 기준
- 현재 하 기준
- 문제점
- 수정안
을 표로 정리해줘.

채점자가 달라져도 비슷한 판단을 할 수 있도록 기준을 더 구체적으로 수정해줘.
```

---

## 5. 형평성 점검하기

```text
현재 루브릭이 특정 학생에게 불리하거나 유리하게 작용할 가능성이 있는지 점검해줘.

다음 기준으로 검토해줘.
- 특정 체격이나 신체 조건에 과도하게 유리한지
- 기존 운동 경험이 많은 학생에게만 유리한지
- 수행 결과만 보고 노력·성장·과정을 완전히 배제하고 있지 않은지
- 장애나 일시적 제한 상황에서 대체 관찰 방법이 필요한지
- 동일한 목표를 다른 방식으로 수행할 여지가 있는지

결과는 '검토 항목 / 잠재적 문제 / 수정 제안' 표로 정리해줘.
의학적 판단은 하지 말아줘.
```

---

## 6. 성취기준과 학습목표 연결 확인하기

```text
현재 체크리스트와 루브릭이 내가 제공한 학습목표와 공식 성취기준에 실제로 연결되는지 검토해줘.

조건:
- 내가 제공한 성취기준 원문만 사용할 것
- 새로운 성취기준 코드나 문구를 만들어내지 말 것
- 직접 연결이 약한 항목은 '연계 약함'이라고 표시
- 평가 항목이 학습목표와 무관하면 삭제 또는 수정 제안

결과는 '평가 요소 / 연결되는 학습목표 / 연결되는 성취기준 / 판단 / 수정 필요 여부' 표로 정리해줘.
```

## 7. 개인정보 없이 평가자료 만들기

```text
현재 평가 실습을 실제 학생 개인정보 없이 수행할 수 있도록 방법을 바꿔줘.

다음 원칙을 반드시 지켜줘.
- 실제 학생 이름·학번·연락처를 사용하지 않기
- 실제 학생의 얼굴·음성이 포함된 영상이나 이미지를 외부 AI 서비스에 업로드하지 않기
- 영상 분석이 필요하면 강사가 제공한 샘플·합성·비식별 자료를 사용하기
- 가능하면 영상 대신 관찰 기록, 성공 횟수, 익명화된 문장 자료를 사용하기

현재 활동에서 어떤 자료를 AI에 입력해도 되는지와
입력하지 말아야 하는지를 표로 구분해줘.
```

## 8. AI가 점수를 자동 확정하지 않게 수정하기

```text
현재 루브릭과 평가 흐름에서 AI가 학생의 최종 점수나 등급을 자동으로 결정하는 부분이 있는지 점검해줘.

있다면 다음 방식으로 수정해줘.
- AI는 체크리스트·루브릭 초안과 관찰 기록 정리를 돕는 역할만 수행
- 최종 점수·등급은 교사가 실제 관찰 자료를 바탕으로 결정
- AI의 제안과 교사의 최종 판단을 구분해서 기록
- 불확실한 경우 '교사 확인 필요'로 표시

수정된 평가 절차를 5단계 이내로 정리해줘.
```

## 9. 최종 체크리스트와 루브릭 다시 작성하기

```text
지금까지 검토한 내용을 반영해 최종 평가도구 초안을 다시 작성해줘.

반드시 반영할 것:
- 관찰 가능한 행동
- 상·중·하 수준의 명확한 구분
- 학습목표 및 내가 제공한 공식 성취기준과의 연계
- 형평성 검토
- 개인정보 보호
- AI가 최종 점수·등급을 자동 확정하지 않음

출력 순서:
1) 관찰 체크리스트
2) 상·중·하 루브릭
3) 교사가 최종 확인해야 할 항목
4) 공식 자료에서 다시 확인해야 할 항목
```

---

## 실습 원칙

- AI가 만든 체크리스트와 루브릭은 **초안**입니다.
- 실제 학생의 식별 가능한 자료는 외부 AI 서비스에 입력하지 않습니다.
- 성취기준은 공식 교육과정 원문과 대조합니다.
- 최종 점수·등급과 예외 상황의 판단은 교사가 직접 결정합니다.
