# Week 4 실습 과제

## 필수 제출

### 1. 3주차 지도안의 평가 출발점 정리
- 학습목표
- 핵심 활동
- 공식 교육과정에서 확인한 성취기준 원문

### 2. 관찰 체크리스트
`prompts.md`의 1번을 사용해 첫 번째 체크리스트를 만들고, 2번으로 모호한 표현을 수정합니다.

### 3. 상·중·하 루브릭
3번으로 루브릭을 만든 뒤 4번으로 수준 구분이 겹치는지 검토합니다.

### 4. 검증
5~8번 중 최소 2개 이상의 프롬프트를 사용해 다음을 점검합니다.

- 형평성
- 성취기준 연계
- 개인정보 보호
- AI가 최종 점수·등급을 자동 확정하지 않는지

### 5. 최종본
9번으로 최종 체크리스트와 루브릭을 다시 작성합니다.

## 수정 전·후 비교

아래 내용을 3가지 이상 작성하세요.

1. 처음에는 어떤 표현이 모호했나요?
2. 상·중·하 단계 중 어떤 기준이 겹쳤나요?
3. 형평성 검토 후 무엇을 수정했나요?
4. 개인정보 보호를 위해 어떤 입력자료를 바꿨나요?
5. AI 결과 중 교사가 최종 판단해야 한다고 느낀 부분은 무엇인가요?

## 권장 제출 형식

- 파일명: `학번_이름_Week4_AI평가`
- 제출 내용: 체크리스트 초안 + 루브릭 초안 + 수정 프롬프트 2개 이상 + 최종본 + 수정 전·후 비교

> 5주차 팀 프로젝트에서 이번 주 최종 체크리스트와 루브릭을 그대로 사용합니다.
