# AI-PE Teacher Training

2026 예비체육교사 AI 융합 역량강화 협력사업을 위한 학생 실습 자료 저장소입니다.

## 사용 방법

현재는 **1주차(제1장: AI 체육 융합의 필요성과 기초지식)** 자료를 먼저 제공합니다.

학생은 아래 순서로 학습합니다.

1. 제1장 교재를 읽습니다.
2. `Week1_AI_Basics/prompts.md`의 프롬프트 중 **필수 실습 1~3**을 수행합니다.
3. `Week1_AI_Basics/practice_tasks.md`의 과제를 정리합니다.
4. AI 답변에서 규칙·수치·안전기준 등 확인이 필요한 부분은 반드시 다시 검토합니다.
5. 실제 학생 개인정보는 외부 AI 서비스에 입력하지 않습니다.

## 자료 구성

- `Week1_AI_Basics/README.md` : 1주차 학습 안내
- `Week1_AI_Basics/prompts.md` : 학생 실습용 프롬프트 명령어
- `Week1_AI_Basics/practice_tasks.md` : 실습 과제 및 제출 내용
- `Week1_AI_Basics/safety_notes.md` : AI 활용 시 주의사항
- `Week1_AI_Basics/video_guide.md` : 교육용 동영상 학습 안내

> 본 자료의 AI 서비스 화면과 기능은 서비스 업데이트에 따라 달라질 수 있습니다. 중요한 사실·규칙·안전 관련 내용은 공식 자료와 교사의 판단을 통해 확인하세요.
